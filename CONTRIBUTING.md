# Участие

```bash
git clone <repo> && cd dsh-telegram
node --test
```

- Один коммит — одна задача, тип `feat:`, `fix:`, `refactor:`, `docs:`, `test:`, `chore:`.
- Тесты обязаны быть зелёными: `node --test`.
- Новые зависимости не добавляем без причины.
- Комментарии только «почему», одна строка. Пересказ кода не нужен.
- Тексты бота и панели — без эмодзи, через `src/i18n.js` (ru/en).

Перед PR: `npm pack --dry-run` — проверь состав пакета.
