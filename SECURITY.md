# Безопасность

## Модель доступа

- Бот отвечает только в приватных чатах; группы и каналы игнорируются.
- Без заданного `ownerId` бот никого не пускает.
- Владелец видит `/log`; участники allowlist — нет.
- Новый человек попадает в доступ только через `ownerId`, allowlist или код `/pair`.

## Секреты

Токен бота хранится в credentials DSH и не возвращается в панель. Файлы состояния и лога — `0600`.

## Логи и данные

- Тексты задач в лог не пишутся: только длина сообщения. Код `/pair` не логируется.
- Входящие документы — `<workspace>/.telegram-inbox/`, права `0600`, лимит 20 МБ.
- Записи о расходе и моделях старше `retentionDays` (30 по умолчанию) удаляются.

до исправления.
