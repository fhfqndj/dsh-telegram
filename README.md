# dsh-telegram

Telegram-мост для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): бот в чате,
сессии DSH за ним и панель настроек в боковой колонке.

Агент работает на вашей машине, а вы читаете и отвечаете из Telegram: ставите задачи, получаете
финалы, подтверждаете инструменты кнопками, отвечаете на вопросы агента.

## Установка

Нужны Node 22+ и DSH 0.2.2-rc.1 или новее.

```bash
npx dsh-telegram-connect install          # прописать мост в профиль desktop
npx dsh-telegram-connect status           # профиль, патч, секреты, лог
npx dsh-telegram-connect uninstall        # убрать мост
```

Пока пакета нет в npm, установка прямо из репозитория:

```bash
npx github:fhfqndj/dsh-telegram install
```

Перезапустите DSH, откройте боковую панель **Telegram** и вставьте токен от
[@BotFather](https://t.me/BotFather). Укажите свой user id в поле «Владелец» и нажмите «Тест» —
бот пришлёт сообщение.

Проверка после установки: `/doctor` в чате, затем `/status`.

## Команды

| Команда | Что делает |
|---|---|
| `/status` | бот, workspace, активная сессия, токены |
| `/sessions` | последние сессии workspace кнопками |
| `/use <номер\|id>` | переключить чат на сессию |
| `/new [название]` | новая сессия |
| `/peek <номер\|id>` | карточка сессии без перехвата |
| `/unbind [id\|all]` | снять привязку чата |
| `/stop` | прервать работу |
| `/steer <текст>` | уточнить текущую работу |
| `/mute`, `/unmute` | заглушить ответы в чате |
| `/notify [on\|off]` | уведомления в этот чат |
| `/quiet [off\|quiet\|normal\|verbose]` | что присылать о работе не из чата |
| `/model [provider/model]` | модель сессии |
| `/cost` | расход токенов |
| `/doctor` | диагностика моста |
| `/log [n]` | последние строки лога (владельцу) |
| `/lang [ru\|en]` | язык ответов |
| `/pair <код>` | подключить этот чат по коду |
| `/help` | список команд |

## Что умеет

- **Задачи из чата.** Текст уходит в активную сессию; фото становится картинкой в промпте,
  документ сохраняется в `<workspace>/.telegram-inbox/`.
- **Ответы.** Финалы приходят rich-сообщением: нативные таблицы, списки, код. Карточка прогресса
  показывает, что агент делает сейчас.
- **Подтверждения.** Инструмент просит разрешение — в чат приходят кнопки «Разрешить»/«Отклонить».
  Политика: `ask`, `trusted` (чтение без вопроса), `yolo`.
- **Вопросы агента.** `ask_user_question` приходит карточкой с вариантами; можно нажать кнопку или
  ответить текстом.
- **Файлы от агента.** Инструмент `telegram_send` присылает текст и/или файл до 50 МБ.
- **Доступ.** Владелец плюс allowlist; новый человек может подключиться по коду `/pair`.
- **Тишина по расписанию.** `/quiet` и `/mute` убирают шум, оставляя вопросы и подтверждения.

## Безопасность

- Только приватные чаты: группы и каналы игнорируются.
- Без `ownerId` бот никого не пускает (fail-closed).
- Токен хранится в credentials DSH; в панели видно «настроен/нет», значение не возвращается.
- Логи без текстов задач: по умолчанию только длина сообщения. `/log` доступен владельцу.
- Входящие файлы — `0600`, лимит 20 МБ. Ретенция записей — 30 дней.

## Разработка

```bash
node --test        # 38 тестов
npm pack --dry-run # состав пакета
```

Структура: `index.js` — композиция плагина, `src/bridge/*` — миксины (доступ, сессии, доставка,
команды, approvals, вопросы, модель, расход), `src/tg/*` — транспорт Bot API, `client.js` — панель.
